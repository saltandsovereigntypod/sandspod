# Nature loops

Real field recordings, looped. Each source is public domain on Wikimedia Commons
(originally from PDSounds.org, which published them as public domain), so no
attribution is required. Trimmed to a steady stretch, the tail crossfaded onto the
head so the loop point is not heard, normalised to about -23 LUFS, mono 44.1 kHz,
AAC 96 kbps (ffmpeg). The website copies live in `assets/sounds/nature/`.

found (the rest were CC BY-SA, or had birds in them), and the synthesised wind
was removed. Saved mixes that used it play without it.
